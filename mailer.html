Template Mailer

Admin only — send an uploaded HTML template to one recipient, via your own email account.

Send through your email (SMTP)

For Gmail this is a 16-char App Password (not your normal password) — create one at myaccount.google.com/apppasswords (needs 2-Step Verification on). Never stored — you type it each time.

Advanced — SMTP server (default: Gmail)

Leave blank for Gmail. Outlook: smtp.office365.com / 587. GoDaddy: smtpout.secureserver.net / 465.
